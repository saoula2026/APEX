Executive System Architecture Summary

APEX is engineered as a Dual-Client B2B SaaS Platform (React Web SPA + React Native Expo Mobile Client) powered by a Metadata-Driven Calculation Engine and a 33-Table PostgreSQL Relational Spine. Every saved estimate atomically snapshots its formula version, material prices, waste margins, and live USD-to-DZD exchange rates.
  • Zero-Deploy Dynamic Formula Engine: Administrators configure N civil engineering categories, equations, and dynamic input fields directly from the database without code deployments.
  • Transactional Cost Snapshotting: Atomic PostgreSQL transactions freeze unit prices, waste factors, and FX rates to protect historical budgets from market volatility.
  • Cross-Platform Field & Office Clients: Shared API contracts serving a responsive React Web SPA and a 35+ screen Expo SDK 52 mobile client with full Arabic RTL mirroring.
  • SaaS Quota & AI Governance: Subscription middleware enforcing per-tier project limits and metered Groq LLaMA-3.3-70B engineering consultations.
